# Routine Mirelion support — 0.8.62.295

Assist previously required a person for every reply; direct support email was separate. This change prepares routine answers using current reviewed instructions, with explicit handover to the existing support inbox. Existing conversations remain with people. New messages create server jobs; the app does not load a model client or add background work to Selection Board.

The model selects reviewed help articles rather than inventing outgoing prose. Faults, repeated unsuccessful advice, sensitive account/billing requests, suggested changes and explicit requests for a person are handed over. Labels identify automated replies. The existing thread header offers Ask a person only while automation is active. Platform replies stop automation; pending/late responses cannot overwrite newer messages, revoked access, a closed conversation or human takeover. Daily and conversation limits bound use. The private queue and existing alert delivery retain human fallback after errors.

A signed Resend receiving adapter and private email delivery queue are included. They preserve email threads in the platform inbox without merging them into club accounts by matching email addresses. Mail recipients come from stored incoming mail, not model output. Incoming duplicate events, automated-message loops, uncertain delivery retries and provider signature failures are covered. The existing support address and VentraIP/Axigen inbox remain in place. Mail forwarding, receiving credentials and a controlled end-to-end email test are separate connection requirements; email remains off until those are verified.

Validation uses synthetic records, mocked providers, the official Svix HMAC test vector and the existing Assist access-control database assertions. No real support conversation or mailbox contents were read, and no test message was sent to a real recipient. The old entry-flow test fixture needed its current password-flow and startup dependencies supplied; the application sign-in logic did not change.

This remains the authorised beta scope.
