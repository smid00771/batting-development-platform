# Dropped players: actual previous line-ups — 0.8.62.299

The comparison previously excluded every unpublished team. A club with completed imported scorecards but unpublished selections could therefore be compared against an older week, producing both false reminders and missed grade drops.

The explicit Show dropped players action now uses the latest completed, linked scorecard line-up where available, with confirmed source-to-roster identities. Actual line-ups take precedence over published selections. It fixes the previous round before matching players, so a missing identity or unavailable recent line-up cannot silently select an older published week. Existing Selection Group, season and format boundaries remain. Cancelled/no-play fixtures and unfinished two-day matches do not become the previous completed round. No player is identified by name, and this comparison does not modify teams or identity links.

Saved reminders accept unpublished prior fixtures and show the previous match date beside the grade. Ordinary reads and Mark as spoken to still use saved reminders without scanning history or scorecards. Previous-captain, coach and selector permissions and shared completion remain. The migration removes derived reminders contradicted by the corrected comparison; it retains all spoken-to records and does not capture new reminders automatically. Existing users should refresh and choose More → Show dropped players again.

The database migration was applied to the existing project on 29 October 2026. Rollback-only synthetic tests cover unpublished actual teams, stale published selections, older returning players, unmatched same-name identities, wrong dates/team/format/status, latest corrections, season isolation, explicit capture, the previous date, and prior-captain completion. The test replaces the historical source function with an exception to prove passive reads and marking do not call it. The existing saved-reminder database tests also pass, including role restrictions, locked teams, idempotent requests, availability and revision checks. No real selection or spoken-to record was changed during testing.

Two new complete-demo tests cover the actual unpublished path, source-date display, safe missing evidence, an ongoing two-day match, persistent completion and quiet refresh. Fictional scorecard identities are now explicitly linked to the fictional roster. Regression suites and deployment/desktop/phone evidence are recorded on the pull request. JavaScript syntax, generated-demo freshness and whitespace checks are required before release. Existing unrelated database advisory categories are unchanged; the new source helper is private, runs as invoker and has no anonymous or authenticated direct execution grant.

Explicit club grade settings support equal-level named teams below the numbered grades. A competition label may be blank, as it can be on manually edited fixtures; grade names, numeric bounds, duplicate checks, administrator access and revision checks remain enforced. Equal-level transfers do not produce dropped-player reminders. No club hierarchy is hardcoded in the product.
