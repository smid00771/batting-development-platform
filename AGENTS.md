# Project writing rule

Keep app copy, instructions and progress updates as short and clear as possible.
Use direct action labels. Avoid repeated explanations, filler and unnecessary warnings.
Include extra detail only when needed for a decision, an error or a requested explanation.

User preference recorded 12 October 2026.

Every button must have one clear action and a visible result. Labels must describe the actual action; avoid inert or ambiguous controls.

Keep each item's current state, actions and relevant help together in its own section. Show saved content where it is managed. Use the same layout for similar tasks, and arrange the page in the order people complete the task.

User design preference recorded 15 October 2026.

Treat vertical space as valuable: avoid empty status areas and repeated controls, and collapse secondary collections by default. Reuse saved club branding across post types.
