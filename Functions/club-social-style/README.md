# Club graphic refinement

Deploy `Functions/club-social-style/index.ts` as `club-social-style` with JWT verification enabled. Include `award-refine.mjs` and the root `social-awards-design.js` and `social-graphic-design.js` dependencies with their relative paths intact.

Version 0.8.62.225 adds `purpose: "graphic_refine"` for Team of the Week, Player of the Week and Team selections. Each uses its existing club-scoped context and saved design revision. Existing team style requests are unchanged. `purpose: "award_refine"` adds natural-language edits to Results, Century and 5 Wickets previews. It validates the signed-in user and club permission, checks the saved design revision, then uses the existing `style_request` allowance and limits (five per hour, thirty per day). Every attempt gets a new server-generated request ID. No new database migration or secret is required; it uses the existing `OPENAI_SOCIAL_STYLE_MODEL` / `OPENAI_GUIDE_MODEL` and `OPENAI_API_KEY` configuration.

The model receives a bounded PNG of the current preview and this club’s saved previous example. It can return only the supported visual settings, short display labels for grades present in the preview, and (for Results) paired result wording (WON/LOST, WIN/LOSS or WIN/DEF) and optional tight matching crop coordinates. Grade labels are stored in layout JSON and never change imported grades or match records. No match facts, asset paths or executable content are accepted as changes. Crop images are fetched only from the saved, club-scoped example under the caller’s JWT. The UI separately labels both crops for review, and the renderer chooses the correct crop from the imported outcome. Draw, tie and no-result labels are always rendered from the imported result.

Suggestions are staged. Apply changes saves the club’s style with optimistic revision checking; confirming the graphic then follows the existing source-signature checks and immutable image workflow. Undo restores the previous layout without another model call. Errors retain the current picture and brief. Artwork changes are forwarded, with their brief, to the existing image preparation/review flow inside the app. The style service never writes images, confirms results or publishes a post.

Measured label-fit warnings offer an abbreviation or a preferred-label input without a model call. Team-selection retries reuse the same settings request ID; uncertain saves offer recovery. The shared controls remain visible beneath previews, and background requests retain their brief when opening the existing image editor.

Validation: run `social_graphic_assistant_test.mjs`, Team/Player of the Week UI tests, team workflow tests and the Results renderer, awards UI/recovery, preparation iteration, `social_awards_refine_service_test.mjs` and `social_awards_refinement_test.mjs` tests. These use mocked provider responses and do not spend club credits. Actual model suggestions and crop accuracy still require review on real club artwork.
